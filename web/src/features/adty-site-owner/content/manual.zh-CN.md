# 分站站长操作手册与注意事项

> **适用对象**：平台分站站长及授权运营管理人员  
> **权限说明**：本手册仅在登录后对分站站长与平台管理员开放展示，不对外公开。所有限额、供货折扣、等级门槛与保证金规则以站长中心后台当前实际展示与平台政策为准。

---

## 1. 开篇必读：分站站长身份与工作台定位

- **纯管理端账号**：分站由平台管理员开通并创建独立的纯管理端站长账号。纯站长账号登录后**仅展示「站点管理」与「账户」两组管理菜单**，无个人 API 密钥、无个人消费钱包，不可用站长账号直接调用模型接口，也不可参与个人推广返佣。
- **数据严格隔离**：站长只能查看与操作归属本站的客户、团队、订单、工单、收益与账务；系统不会向站长暴露上游模型渠道、平台内部运营钱包或其他分站数据。
- **侧边栏结构**：
  - **站点管理**：`站点概览`、`客户`、`团队管理`、`订单管理`、`定价与倍率`、`充值赠送`、`推广管理`、`收益明细`、`收益提现`、`结算单`、`站长钱包`、`兑换码`、`通知`、`员工账号`、`工单管理`、`基本身份验证`、`邮件配置`、`站点设置`、`站长操作手册`。
  - **账户**：`历史分站账务`（名下曾有关闭或转让历史分站时显示）、`安全与访问`。

## 2. 新站上线快速初始化清单

拿到站长账号与默认域名后，建议按以下顺序完成初始化配置：

1. **开启双重验证（2FA）**（`安全与访问`）：绑定 TOTP 验证器并妥善离线保存恢复码。后续调价、发兑换码、提现、重置客户密码、管理员工等高敏操作均会触发二次身份验证。
2. **完善站点品牌与客服**（`站点设置 → 品牌`）：填写站点名称、网站标题、站点公告、钱包页提示、客服联系方式，上传 PNG/JPEG/WebP 格式 Logo（≤ 200 KB）并点击 **「保存品牌」**；如需在线客服，同时填齐 Tawk.to 的 `property_id` 与 `widget_id`。
3. **绑定自定义双域名（可选）**（`站点设置 → 自定义域名`）：准备两个**不同的子域名**（如 `www.yourdomain.com` 作网站域名、`api.yourdomain.com` 作 API 域名，**严禁使用根域名**）同时提交，按页面生成的记录在您的 DNS 服务商添加 **2 条默认线路 `CNAME`** 指向目标地址后（常规绑定无需 TXT；仅认领历史上曾被其他分站绑过的域名时需额外补 1 条归属 TXT），直接点击 **「立即检测 DNS」** 触发核验并在 72 小时内自动签发 HTTPS 证书生效；如需优化国内首页速度，可按需展开网站域名卡片内的 **「中国大陆首页加速（可选）」** 配置 `_acme-challenge` 委托并点击 **「立即检测证书」**，待域名生效且边缘证书就绪后再加大陆线路 CNAME。
4. **配置多语言法律条款**（`站点设置 → 多语言法律页面`）：分站**不会继承**主站条款；按需填写中文（`zh-CN`）与英文（`en`）版「用户协议」「隐私政策」「退款政策」，填写用户协议或隐私政策后将自动开启注册同意勾选框与页脚链接。
5. **配置发件邮箱并测试**（`邮件配置`）：分站不提供平台默认发信通道，请先配置**自定义 SMTP** 或 **自有 Resend API** 并点击 **「保存」**，再发一封测试邮件确认可正常送达；未配置前分站注册验证、找回密码、涨价通知等邮件将直接报错提示先配置。
6. **配置基本身份验证**（`基本身份验证`）：分站独立管理密码登录、新用户注册、密码注册、邮箱验证（**默认关闭**，须先完成第 5 步邮件配置才可开启）以及邮箱域名/别名限制与白名单，与主站配置完全隔离。
7. **核对供货折扣并设定零售倍率**（`站点概览` → `定价与倍率`）：查看当前分站供货折扣 `cost_factor`，设置合理的全站零售倍率（`1.0x ~ 10.0x`，默认 `1.0x` 无差价）。
8. **按需配置营销工具**（`充值赠送` / `推广管理`）：开启前务必确认**收益钱包可用余额**或**获主站授权的保证金周期可用额度**充足，避免拦截客户下单。

## 3. 分站管理菜单逐项使用指南

### 3.1 站点概览

- 查看选定日期区间内的核心经营指标：新增客户、付费客户、活跃客户、客户消费额、平台供货成本、站长差价收益、充值赠送支出、退款额及按日趋势。
- 顶部展示站点当前状态（`active` 正常营业 / `closing` 关站公示倒计时）、站点地址、API 地址及当前供货折扣（`cost_factor`）。
- 若出现「未计入收益（`skipped_usd`）」，仅表示存在疑似风控待平台复核的消费记录，不代表资金丢失。

### 3.2 客户管理

- **客户列表**：按注册时间倒序分页（20 条/页），自动排除分站员工账号与团队独立员工子账号。
- **可见性策略**：客户邮箱（默认打码，如 `a***@example.com`）、余额、充值记录、用量、请求日志、API 密钥列表的可见性受平台策略控制。请求日志自动剥离客户 IP 与内部渠道信息，API 密钥**永远不显示明文 Key**。
- **精确查找**：仅支持输入**完整用户名或完整邮箱**精确查询，不支持模糊搜索；受每小时查询次数限制（平台默认 **20 次/小时**，**无论是否查到均计次**），且每次查询留审计记录。
- **重置客户密码**：支持手动指定（8–128 字符）或一键生成随机密码（12 / 16 / 20 / 24 位，明文**仅显示一次**）。保存后立即吊销该客户全部旧会话与 PAT 令牌；**需二次身份验证**；关站公示期不可操作。
- **举报客户**：发现异常或违规客户可填写理由（≤ 1000 字符）提交平台风控核查。
- **重要说明**：**站长手动给客户直接加余额的功能已停用**。如需给客户线下发放额度，请统一前往 **`兑换码`** 页面生成本站客户兑换码交由客户核销。

### 3.3 团队管理

包含三个页签（`团队`、`创建团队`、`团队注册链接`），与主站团队管理保持同等完整能力：

1. **团队列表与详情（`团队`）**：查看本站活跃/已关闭团队列表、成员列表、团队绑定 API 密钥状态与团队共享余额流水。
2. **创建团队（`创建团队`）**：从本站启用客户中指定唯一团队负责人，设定团队名称（1–64 字符）与供货价倍率（`1.0` ~ `10.0`，留空默认 `1.0`）；不支持跨站指定客户，关站公示期不可创建。
3. **团队注册链接（`团队注册链接`）**：可按有效期（1–168 小时）签发一次性本站团队注册链接（明文仅显示一次，自动使用本站公开域名），也可查看历史链接并**撤销（Revoke）**尚未使用的高危/过期链接。
4. **调整活跃团队的供货价协议倍率**：允许范围 **`1.0` ~ `10.0`**（最多 4 位小数），计费公式为 `团队结算价 = 分站供货价 × 团队协议倍率`，不可低于 `1.0x` 底线。修改后仅影响新产生的团队请求，不改变现有余额。
5. **边界说明**：手动给团队直接加余额功能保持永久停用，团队充值由团队负责人在线完成。

### 3.4 订单管理与客户退款

- 支持按订单号（`trade_no`）、用户名、链上哈希（`tx_hash`）、订单类型、状态与支付方式筛选本站统一订单。
- **站长人工退款**：可对本站**客户订单**发起部分或全额人工退款，并按 7 步状态机推进：`发起退款 → 审批 → 回收客户额度 → 赠金处理 → 佣金追回 → 录入线下打款凭证 → 完结`（或中途终止）。
- 发起与每一步状态推进均需**绑定请求摘要的二次身份验证**；禁止对站长自身保证金充值单发起退款。

### 3.5 定价与倍率

- **全站单一零售倍率**：统一配置一个全站零售倍率 `M`，合法区间 **`1.0` ~ `10.0`**（最多 4 位小数，默认 `1.0`）。
- **核心收益公式**：
  - `分站供货价 = 主站分组价 × 分站供货折扣 (d)`
  - `客户实际售价 = 分站供货价 × 零售倍率 (M) = 主站分组价 × d × M`
  - `站长单次收益 = 客户实扣美元 - 平台供货成本美元 = 平台供货成本 × (M - 1)`
- **生效时机与邮件提醒**：
  - 零售倍率保存后**立即生效**，需**二次身份验证**。
  - **每次上调倍率时，系统会自动向本站所有绑定邮箱的客户发送涨价通知邮件**（新价格仅适用于生效后的新请求）。请慎重评估后再调价，避免高频来回调整。

### 3.6 充值赠送

- **仅支持 USDT 配置**：主站启用 USDT 支付后，分站可直接自主开关并配置本站 **USDT** 充值赠送比例（覆盖 TRC20 / ERC20 / BEP20 / Polygon / X Layer 全部收款链并共用同一规则；支付宝与微信支付不提供充值赠送），比例范围 `0% ~ 100%`。仅适用于普通客户在线 USDT 钱包充值，不适用于团队充值或站长保证金充值；保存需**二次身份验证**。
- **资金预冻结提醒**：
  - 客户创建在线 USDT 充值单的瞬间即预冻结对应赠金：优先冻结**收益钱包可用余额**；不足时仅在已获平台开启「赠金保证金兜底」授权的情况下动用**保证金周期可用额度**。
  - **若可用余额不足以覆盖本次赠金，客户创建在线 USDT 充值单会直接报错失败。**
  - 订单取消或过期后预冻结赠金自动退回；客户退款时仅按**尚未消费的剩余赠金比例**冲回，已消耗赠金不退还。

### 3.7 推广管理

包含顶部核心指标、「补足待覆盖佣金」按钮及 5 个页签（`提现审核`、`推广员`、`佣金明细`、`操作记录`、`设置`）。

- **开启前提**：
  1. `默认佣金比例`：**`0% ~ 30%`**（分站硬上限 30%）。
  2. `待覆盖佣金上限（USD）`：必须 **`> 0`**。
  3. `冻结期 / 观察期（天）`：整数 **`>= 0`**。
- **风控与归因**：一级直推、禁止自邀/循环互邀；被邀请人须在首笔已支付订单前绑定；团队充值不计佣。可配置 Cookie 有效期、取消窗口、自邀检测窗口及批量注册阈值。
- **资金覆盖**：优先冻结收益钱包可用余额，不足时仅在获平台授权后动用保证金周期可用额度；资金不足时进入 `待覆盖（pending_coverage）`，**观察期倒计时仅在佣金 100% 资金覆盖后才开始计算**。
- **推广员兑现**：
  - **转入本站余额**：0 手续费、无门槛、即时到账，免审核。
  - **外部现金提现**：可自主勾选启用 **USDT**（支持 `TRC20 / BEP20 / POLYGON / XLAYER`）和/或 **支付宝**（需设汇率），不支持微信支付。审核批准后由**站长自行线下转账**并回填 `TxID` 或上传打款凭证图（≤ 5 MB）。
- **文档自动同步**：本站开启或调整默认佣金比例、观察期与提现方式后，本站 `/docs/` 文档中的「推广返佣计划」页面会自动同步最新数值；关闭推广时文档侧边栏入口也会自动隐藏。

### 3.8 收益明细与数据导出

- 按单笔 API 请求展示模型、分组、客户 ID、请求 ID、客户消费额与站长差价收益（每页 50 条）。
- 支持导出「收益流水」「经营报表」「客户汇总」3 种 CSV（单次上限 100,000 行，自动防护公式注入，客户汇总邮箱强制打码）。

### 3.9 收益提现

- **唯一提现方式：USDT 四链**：`TRC20`（`T` 开头）以及 `BEP20 / POLYGON / XLAYER`（`0x` 开头）；不支持支付宝提现。
- 最低提现额、手续费与汇率以页面实时展示为准，提交需**摘要绑定的二次身份验证**。
- 已确认的消费差价收益实时计入可用收益余额；如触发日结对账挂起提示，请及时联系平台客服核对。
- 提现申请在 `pending`（待审核）状态可自助撤销，进入 `paying`（打款中）后不可撤销。

### 3.10 结算单

- 每日按营业日时区（默认 `Asia/Shanghai`）自动生成上一营业日对账单；若事后发生退款或补账，会保留历史修订版本可供切换对比。
- 支持一键 **导出 CSV** 或 **另存为 PDF** 归档。

### 3.11 站长钱包、保证金机制与分站等级

页面展示 **收益钱包（`earnings`）** 与 **保证金钱包（`margin`）** 两项独立账户及明细流水。

#### 保证金钱包两套独立额度池

| 额度池 | 适用业务 | 需平台额外授权 | 说明 |
|---|---|---|---|
| **90% 周期额度**（保留 10% 留存底线） | 客户在线充值赠送垫付、推广佣金覆盖垫付 | **是**（两项独立开关） | 周期额度用满后，须发生一笔**真实新入账**（在线充保证金、收益转保证金、兑换保证金充值码或平台人工入账）开启新周期并补发积压项 |
| **超额保证金**（100% 等级押金底线之上） | 发放本站客户兑换码（收益不足时自动补足） | **否**（自动启用） | 不消耗 90% 周期额度，也不可击穿当前等级押金底线；具体押金要求以本页与平台规则为准 |

- **保证金充值途径**：在线支付充值保证金（支持平台已启用的易支付与 USDT 收款链；易支付前台按美元展示应付金额）、可用收益一键转入保证金（免二次验证，立即开启新周期）、或兑换平台发放的保证金充值码（`site_margin`）。
- **分站等级考核**：以本站历史累计净有效客户充值本金为考核依据（站长自身充值、保证金充值、团队充值均不计入）。具体等级划分与供货折扣政策请以当前站点后台配置为准或咨询平台客服。

### 3.12 兑换码

- 站长可批量发放供本站普通客户使用的**额度兑换码（`site_customer`）**，单码面额 `> 0` 且 `≤ $100,000`（最多 2 位小数），单批 `1 ~ 100` 个，须填写发放理由。
- 出资顺序：**可用收益优先 → 不足部分自动冻结超额保证金**。
- **两条铁律**：
  1. **明文仅显示一次**：生成弹窗关闭后不可再查明文，请当场复制或导出 `.txt` / `.csv`。
  2. **「冻结」不可逆，没有「解冻」按钮**：冻结仅阻止核销，不退还资金；如需退回锁定资金，必须执行 **「作废（Cancel）」**。
- 发放、冻结、作废均须**二次身份验证**。

### 3.13 通知与公告管理

- **站内公告**：可定向发布给「本站普通用户」和/或「本站团队用户」。标题 ≤ 120 字符，正文支持 Markdown/富文本（自动安全净化，纯文本上限 2000 字符）。
- 公告**一旦发布不可退回草稿，只能撤回**（撤回后只读留档）。

### 3.14 员工账号管理

- **强安全限制**：本菜单**仅限浏览器直接登录操作，严禁 PAT 调用**；创建、编辑、改密、删除员工均需**摘要绑定的二次身份验证**。
- 用户名 ≤ 20 字符（不含 `@`，全平台唯一）；**员工密码强制 15–128 字符**。
- 可按最小权限分配 6 项权限：`处理工单`、`查看客户`、`查看余额`、`查看充值`、`查看用量`、`禁用客户`。
- 员工永远不可见站长钱包/收益/提现、客户明文邮箱、客户 API 密钥，也不可重置客户密码。
- 修改资料/改密/禁用/删除员工都会**立即踢出该员工在线会话**；禁用或取消工单权限时，其未完结工单自动释放回待分配队列。

### 3.15 工单管理

- 集中处理本站客户工单，支持筛选与导出 JSON，支持「公开回复」与「内部备注」，可指派给站长或具工单权限的启用员工。
- 附件单张 ≤ 5 MB、单工单 ≤ 6 张、总大小 ≤ 20 MB；文本会自动脱敏疑似 API Key。

### 3.16 基本身份验证

独立管理本站客户的登录、注册与邮箱校验规则（与主站全局配置完全隔离、不继承主站开关），保存需**二次身份验证**：

- **允许通过密码登录**（默认开）、**允许新用户注册**（默认开）、**允许通过密码注册**（默认开）。
- **启用邮箱验证**（**分站默认关**）：必须在 **`邮件配置`** 保存有效的自定义 SMTP 或自有 Resend 后才可开启，未配置发信时页面置灰禁用、服务端同步拦截。
- **启用邮箱域名限制**（默认关）与 **邮箱域名白名单**（最多 200 个域名；开启域名限制时白名单不可为空）、**启用邮箱别名限制**（默认关，禁止 `+` 别名）。

### 3.17 邮件配置

支持两种互斥的自有发信模式（密钥加密存储、永不明文回显）：
1. **自定义 SMTP（`smtp`）**：配置服务器、端口、加密方式、账号与密码/授权码；严禁填写 `localhost` 或私有内网 IP（SSRF 拦截）。
2. **自有 Resend API（`resend`）**：填写您已在 Resend 验证过域名的 API Key 与发件邮箱。

- **未配置策略**：不提供平台默认发信通道。在保存有效的 SMTP 或 Resend 配置前，本站业务发信（验证码、密码重置、涨价通知、测试邮件）会直接报错提示先配置（官方关站迁移邮件仍由平台兜底发送）。
- **重要**：每次修改后请**先点「保存」再发送测试邮件**。

### 3.18 站点设置

1. **品牌**：站点名称、网站标题、公告、钱包提示、客服联系方式、自定义文档链接（留空自动使用内置白标 `/docs/`）、Tawk.to 双 ID 以及 Logo / Favicon（PNG/JPEG/WebP，≤ 200 KB；**上传后须再点「保存品牌」**）。
2. **自定义首页**：支持 Markdown、HTML 或外部链接嵌入；留空恢复默认首页。
3. **多语言法律条款**：独立维护中/英文「用户协议」「隐私政策」「退款政策」及退款政策展示开关（完全独立，不继承主站）。
4. **自定义域名**：
   - 须成对提交两个**不同的子域名**（`网站域名` + `API 域名`，**严禁使用根域名**），并在 **72 小时**内按页面生成的解析清单添加 **2 条默认线路 `CNAME`** 记录（指向平台默认 CNAME 目标，常规绑定**无需添加 TXT**，Cloudflare 会在 CNAME 生效后自动通过 HTTP 完成所有权与 SSL 签发；若使用 Cloudflare 解析，请关闭小云朵保持「仅 DNS」；仅当认领历史上曾被其他分站绑定过的域名时，为防悬空 CNAME 劫持才需额外添加 1 条归属 TXT）。
   - **DNS 主机记录填写提示**：大多数 DNS 服务商（如阿里云 DNS、Cloudflare）会自动补全根域名，填写主机记录时请**去掉末尾根域名**（例如 `api.yourdomain.com` 的 CNAME 主机填 `api`，`www.yourdomain.com` 填 `www`），切勿重复拼接根域名导致长期验证失败。
   - **自动检测频率与「立即检测 DNS」**：CNAME 尚未生效时后台按指数退避自动重试（30 秒起逐步翻倍、最长 1 小时），验证通过后固定每 5 分钟检查一次直至证书签发并生效；配好解析后无需等待退避，可直接在待验证域名卡片点击 **「立即检测 DNS」** 立即触发一次核验并实时刷新状态（单域名冷却 10 秒，免二次验证）。
   - **双域边界**：`网站域名` 仅用于网页与控制台（调用 `/v1` 会返回 403）；`API 域名` 供客户端配置 Base URL（同时支持网页访问且永不被收录）。
   - **中国大陆首页加速（可选，默认折叠）**：仅适用于自定义**网站域名**。如需优化中国大陆访客的首页打开速度，可在网站域名卡片展开 **「中国大陆首页加速（可选）」**：第 1 步在默认线路添加 `_acme-challenge` CNAME 委托（可在等待自定义域名生效时一并添加，支持点击 **「立即检测证书」** 加速触发签发，无需等待域名先激活）；待**域名生效且边缘证书「就绪」**后，页面会自动解锁第 2 步，按提示新增中国大陆线路 CNAME 指向平台大陆目标（需支持分线路解析，如阿里云 DNS / DNSPod）。**切勿为 API 域名配置大陆线路**。
5. **搜索引擎**：控制网站域名的收录开关（API 域名始终 `noindex`）。
6. **申请关闭站点**：提交理由等待平台审核排期，不会立即关停。

### 3.19 历史分站账务

名下存在已关闭或曾转让的历史分站时，可在此切换历史站点，查看归属期间的收益明细、继续申请与追踪 USDT 提现、导出历史结算单，以及清理遗留的归档网站域名。

### 3.20 安全与访问

管理登录密码、绑定邮箱、查看/吊销活跃会话、管理 2FA 以及签发个人访问令牌（PAT）。使用 PAT 调用站长管理接口时，请按最小权限勾选对应的 `site_owner_*` 作用域；以站长身份访问工单接口（`/api/adty/tickets*`）时，读操作（GET）需**同时**勾选 `profile:read` + `site_owner_customer:read`，写操作需**同时**勾选 `profile:write` + `site_owner_customer:write`（员工管理接口严禁 PAT）。

## 5. 关站流程、公示期限制与资产处置

- **公示期（`status = closing`）**：平台批准关站并设置执行时间后，系统向客户发送迁移通知并关闭新注册。公示期内**禁止**改价、改赠金、发/管兑换码、修改站点配置、重置客户密码、发公告、新增或扩权员工；**允许**继续提现站长收益、审核存量佣金提现、处理存量工单、禁用/删除员工及删除自定义域名。
- **到期关站后**：
  1. 客户与团队自动迁入主站，余额与历史订单完整保留；原有 API Key 失效，客户用原账号登录主站重新生成即可。
  2. 站长合法可用收益不倒扣，可在 `历史分站账务` 中继续提现至 USDT。
  3. 未核销的客户兑换码由主站继承，仅限原分站迁移客户核销；未核销保证金充值码自动作废释放。
  4. 未完结工单移交主站接管；自定义网站域名自动转为跳转主站状态，API 域名自动解绑清理。

## 6. 站长高频踩坑与运营红线

1. **开「USDT 充值赠送」前先查余额与授权**：充值赠送仅支持 USDT；收益不足且未获保证金兜底授权时，客户创建在线 USDT 充值单会直接报错。
2. **切勿混淆保证金两套额度池**：90% 周期额度用于获授权的赠金/佣金垫付，超额保证金才用于发兑换码。
3. **调高零售倍率会立即生效并向客户群发涨价邮件**：保存前务必核对小数位，避免频繁调整。
4. **兑换码明文只显示一次，冻结不可解冻**：生成当场导出保存；退回资金请用「作废」。
5. **线下发额一律走兑换码**：手动给客户或团队直接加余额已停用。
6. **分站升级只计有效客户净充值本金**：站长自身充值、保证金与团队充值不计入业绩。
7. **收益提现仅支持 USDT 四链**：务必核对网络与地址前缀（`TRC20` 为 `T` 开头，EVM 三链为 `0x` 开头）。
8. **推广计划「转入余额」始终 0 费率免审**：启用推广前请测算利润空间；佣金观察期在 100% 资金覆盖后才开始计时。
9. **推广员现金提现需站长自行线下转账并回填凭证**：支持 USDT/支付宝，不支持微信支付。
10. **自定义域名禁止根域名、切勿重复填根域后缀，务必告知客户填写 API 域名**：常规绑定只需加 2 条默认线路 CNAME（如用 Cloudflare 解析须关闭小云朵），加完即可点「立即检测 DNS」快速核验；网站域名调用模型会 403；大陆加速为可选项，仅配置于自定义网站域名且必须等域名生效与 `_acme-challenge` 证书就绪后再切大陆线路。
11. **分站法律条款完全独立不继承主站**：按需在「站点设置 → 多语言法律页面」填写中英文条款。
12. **自建 SMTP 禁填内网地址，测试前先保存**；**上传 Logo 后别忘了点「保存品牌」**。
13. **客户精确查找按次扣配额（查不到也扣）**：默认 20 次/小时，请输完整用户名或邮箱。
14. **员工密码至少 15 位，改密/改权会立刻踢下线**：减权或禁用会同步释放其未完结工单。
