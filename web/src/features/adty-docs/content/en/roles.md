# Role guides

## User

After registration, open the wallet to see the USD balance, principal, and bonus. Create an API key and put the API base URL and key in the client.

## Team lead

Only Root can create a team and appoint its lead. The lead can invite members and authorize them to use team API keys. Usage of those keys is charged to the team's shared balance. If the lead leaves the team or closes their account, the team enters the closure process.

## Team member

Accept one invitation and use the team key. A person can belong to only one team. Leaving the team does not charge the personal wallet.

## Site owner

Set the brand, retail price, and site gift. Earnings go to the earnings wallet. Margin draws follow the open cycle. Finish open orders before closing the site.

## Site staff

Handle customers and tickets of this site only within granted permissions. Staff cannot issue refunds or request customer balance adjustments; customer credits are issued by the site owner via site redemption codes.

## Main-site admin

System settings, supply prices and site tiers, opening or closing subsites, and creating teams are Root-only; regular main-site admins handle delegated operations within their granted permissions. Payments, refunds, and adjustments must write a ledger row. Do not edit a balance by hand.
