# 角色使用说明

## 普通用户

注册后在钱包查看美元余额、本金和赠金。创建 API Key 后，把 API 地址和 Key 配到客户端即可调用。

## 团队负责人

只有 Root 可以创建团队并指定负责人。负责人可以邀请成员并授权成员使用团队 API Key。这些 Key 产生的费用从团队共享余额扣除。负责人退出团队或注销账号时，团队进入关闭流程。

## 团队成员

接受邀请后使用团队 Key。不能同时加入两个团队。退出后团队 Key 不再扣你的个人余额。

## 分站站长

配置品牌、售价和本站赠金。收益进收益钱包，保证金按周期动用。关站前先处理未完成订单。

## 分站员工

仅在授权范围内处理本站客户与工单，禁止直接退款或发起客户余额调整；发放客户额度由站长签发站点兑换码完成。

## 主站管理员

系统设置、供货价与分站等级、开设/关闭分站、创建团队仅限 Root；普通主站管理员按获授权限处理委托运营业务。支付、退款和调额都要留下流水，不能直接改余额。
