# 常见问题

## 怎么充值？

打开[钱包](/wallet)，选金额和支付方式（USDT、支付宝或微信支付，以页面上开放的为准），在弹出的支付窗里付款。确认到账后余额自动增加，不用一直停在页面上。最低充值金额和充值赠送都显示在钱包页。

## 付了款但余额没变

USDT 要等链上确认后才入账，可能要几分钟。支付宝、微信一般一分钟内到账。超过 30 分钟余额还没变，请带上[钱包](/wallet)里显示的订单号联系客服。

## 怎么计费？

按量计费。每次请求按实际用掉的 tokens 扣费（部分模型按次或按张），单价见[模型价格](/pricing)页。[使用日志](/usage-logs)里能看到每次请求的费用。没有月费。

## 能开发票吗？

详情请咨询客服。

## 能退款吗？

请看[退款政策](/refund-policy)。

## 能用哪些模型？

每把 API 密钥都绑定到明确分组，可调用[模型价格](/pricing)页中所属分组开放的模型，模型名照页面上的原样填写。如果需要调用不同分组的模型，请在[令牌](/keys)页为对应分组分别创建密钥。

## 一个密钥能在多个工具里用吗？

可以，但更推荐在[令牌](/keys)页给每个工具建一个密钥。这样每个工具的用量分开看，停用其中一个也不影响别的。

## 会保存我的数据吗？

不保存任何数据。

## 怎么推广赚钱？

加入[推广计划](/affiliate)：分享你的链接，你邀请的人充值后你可以拿佣金。

## 还有问题

请登录后前往站内[支持中心](/support)提交工单，或查看控制台站内公告获取支持信息。
