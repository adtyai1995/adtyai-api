# Legal & Policies

ADTY AI publishes clear service agreements, privacy commitments, and refund terms directly on the platform console. When accessed through any site deployment, each legal document automatically reflects the active site's published policies.

## Published Legal Documents

- **[User Agreement](https://www.adtyai.com/legal/user-agreement)** — Terms of service governing account registration, API access, service availability, and acceptable usage.
- **[Privacy Policy](https://www.adtyai.com/legal/privacy-policy)** — How account credentials, security logs, billing records, and API request metadata are collected, processed, and protected.
- **[Refund Policy](https://www.adtyai.com/legal/refund-policy)** — Eligibility criteria, processing procedures, and timelines for top-up disputes and eligible refund requests.

## Acceptable Use Summary

By creating an account or sending API requests through `https://api.adtyai.com`, you agree to use the service responsibly and lawfully:

- **Lawful & compliant workloads**: Do not use the gateway for illegal activities, malware generation, unauthorized intrusion, harassment, fraud, or content prohibited by applicable law or upstream model provider policies.
- **Account & credential integrity**: Keep your account credentials, 2FA recovery codes, Personal Access Tokens, and `sk-...` API keys confidential. Do not engage in credential harvesting, automated fake account creation, or referral manipulation.
- **Fair network behavior**: Respect per-key quotas, concurrency rules, and upstream rate limits. Do not attempt to probe, overload, bypass authentication, or disrupt gateway infrastructure.

::: warning Enforcement
Accounts that violate the User Agreement or abuse billing, voucher, or referral mechanisms may have affected keys suspended or accounts restricted pending review.
:::

## Billing Transparency

ADTY AI is built around straightforward, verifiable usage accounting:

- **USD-denominated wallet**: All wallet balances, voucher credits, and per-request deductions are tracked in USD.
- **Pay-as-you-go metering**: Charges are calculated strictly from actual model usage—including input tokens, output tokens, cached tokens, reasoning tokens, or generated image units—multiplied by the published rate of the model group bound to your API key.
- **Auditable usage logs**: Every billed API request is logged in the console under **Usage Logs** with a timestamp, model identifier, token breakdown, exact USD cost, latency, and Request ID.
- **No surprise charges**: Standard API usage draws exclusively from your prepaid wallet balance (or shared team wallet) and stops cleanly once a key cap or account balance is reached.

For billing inquiries or policy questions, please open a ticket through the [Support Center](/guides/support).
