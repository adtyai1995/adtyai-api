# Support Center

Need help with a top-up order, API error, model group question, or account security issue? Submit a ticket directly inside the console at [https://www.adtyai.com](https://www.adtyai.com).

## Opening a Support Ticket

1. Sign in to [https://www.adtyai.com](https://www.adtyai.com) and open **Support** (Tickets) from the sidebar.
2. Click **New Ticket** and choose the **category** that best fits your issue (for example, Billing & Top-Up, API & Models, Account Security, or General Inquiry).
3. Enter a clear subject line and concise description of what happened, what you expected, and how to reproduce it.
4. Submit the ticket to start a tracked conversation with support staff.

### Details That Speed Up Resolution

Including concrete diagnostic details in your first message helps our team resolve issues much faster:

- **API issues**: Request ID from **Usage Logs**, timestamp, model name, HTTP status code, and the exact error JSON (without your full API key).
- **Billing or top-up issues**: Order number, payment method, payment time, and payment confirmation screenshot.
- **Client configuration issues**: Client name/version (e.g., Claude Code, Codex CLI, Cherry Studio), operating system, and sanitized config snippet.

## Attaching Screenshots

You can upload visual evidence directly inside the ticket composer or reply box:

- **Maximum file size**: up to **5 MB per image**
- **Maximum attachments**: up to **6 images per ticket**

Crop out unrelated personal information when capturing payment receipts or terminal screens.

## Automatic API Key Redaction

As a built-in safety net, the ticket system automatically detects and redacts standard `sk-...` API keys found in ticket descriptions and replies before storing them.

::: tip Still Best Practice to Redact Locally
Even with automatic key masking enabled, avoid pasting full API keys, Personal Access Tokens, passwords, or 2FA recovery codes into ticket messages or screenshots. If a key was accidentally shown in a screenshot, revoke and rotate it immediately in **API Keys**.
:::

## Checking Replies & Following Up

- Open **Support** in the console at any time to check ticket status (`Open`, `Replied`, `Resolved` / `Closed`) and read staff responses.
- Reply within the same ticket thread if follow-up information is needed rather than opening duplicate tickets for the same issue.
- Once your issue is resolved, you can mark the ticket closed directly from the thread view.
