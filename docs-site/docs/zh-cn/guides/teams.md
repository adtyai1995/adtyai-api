# 团队协作与共享钱包

ADTY AI 团队功能面向企业研发团队、工作室与科研小组，提供统一的美元共享钱包、清晰的角色权限模型与可追溯的共享钱包流水管理。

## 团队共享钱包

告别个人垫付报销或多人共用同一把个人 API Key 的隐患：

- **团队负责人（Owner）**向团队空间内的**共享钱包**统一充值美元余额。
- 团队负责人或团队员工使用的**团队专属 API Key**在调用模型时，直接从团队共享钱包实时扣费。
- 团队负责人原有的个人钱包与个人密钥仍与团队计费完全隔离，互不干扰。

::: tip 坚持“一人一 Key”原则
建议团队内每位成员都自行创建并绑定本人专属的团队 API Key，而非线下转发同一把密钥。这样既能保持成员密钥隔离，又能在成员离职时单独吊销其权限而不影响团队其他人。
:::

## 角色模型说明

团队空间支持两类明确划分的角色：

| 身份角色 | 适用对象 | 钱包与计费方式 | 生命周期控制 |
| :--- | :--- | :--- | :--- |
| **团队负责人（Owner）** | 团队负责人或财务管理员 | 负责为共享钱包充值与管理团队预算；个人钱包与个人密钥保持独立 | 负责创建/管理员工子账号、签发一次性邀请链接、查看与吊销团队已绑定 Key，以及查阅团队充值记录与共享钱包流水 |
| **独立团队员工子账号（Independent Team Employee）** | 归属于当前团队的内部员工专用账号 | 仅在团队空间内运行并走共享钱包计费（不与外部个人空间混用或切换） | 由团队负责人直接创建，或由员工通过一次性邀请链接注册；可由负责人随时启停、改密或移出 |

### 团队员工的两种开通方式

团队员工均以归属团队的**独立团队员工子账号**身份使用团队空间，不支持将已有普通个人账号并入团队或在个人/团队空间之间自由切换。员工子账号可通过以下两种方式开通：

- **负责人直接创建**：由团队负责人在后台直接为员工或外包协作者创建独立团队子账号，登录凭据与生命周期完全由团队统一管控。
- **一次性邀请链接注册**：由团队负责人签发一次性团队邀请链接，员工打开链接后自行注册归属该团队的独立团队子账号。

## 创建并绑定团队 API Key

每位活跃团队成员（团队负责人或独立团队员工子账号）均需自行创建并绑定本人名下的 API Key，团队负责人不能代员工绑定 Key：

1. 登录控制台 [https://www.adtyai.com](https://www.adtyai.com)，前往 **API 密钥（`/keys`）** 创建个人 `sk-...` API Key。
2. 为该令牌选择一个具体模型分组（详见[渠道可用性与分组选择](/zh-cn/guides/channel-status)），并按需设置单 Key 美元消费上限、允许调用的模型列表、IP 白名单与过期时间。
3. 前往 **我的团队（`/my-team`）**，输入本人该令牌的 **Token ID** 并点击绑定，将**本人名下**的 Key 绑定到团队。
4. 将已绑定团队的 `sk-...` 密钥配置到本人的 CLI、IDE 或业务服务中。

绑定生效后，所有使用该 Key 发起的请求都将自动从**团队共享钱包**实时扣费，并记入团队共享钱包流水。

## 用量可见性与财务对账

- **团队负责人（Owner）**：可在 **我的团队（`/my-team`）** 查看团队**共享钱包余额**、**团队充值记录**、**共享钱包流水**、**成员列表**以及全部**团队已绑定 Key** 的状态与吊销管理。平台不提供跨成员调用日志明细或跨成员模型分布汇总接口；包括负责人在内的每位成员均在 **使用日志（`/usage-logs`）** 查阅本人调用日志。
- **独立团队员工子账号**：可在 **我的团队（`/my-team`）** 查看并管理本人已绑定的团队 Key，并在 **使用日志（`/usage-logs`）** 查看本人调用日志、Token 拆解与 Request ID，便于自查缓存命中与排查报错，同时不会看到其他成员的密钥与调用数据。

## 成员移出即时生效

团队安全回收在网关层实时执行，无需等待缓存过期：

- 一旦禁用或移出某个**独立团队员工子账号**，该账号关联的全部团队专属 API Key 会**立即失效并被拦截**，无法继续产生任何扣费。
- 团队内其他员工正常使用中的 API Key 不受任何影响。
- 历史共享钱包流水仍会完整保留，方便后续对账与合规留痕。
