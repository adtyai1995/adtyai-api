# 团队协作与共享钱包

ADTY AI 团队功能面向企业研发团队、工作室与科研小组，提供统一的美元共享钱包、清晰的角色权限模型与精细化的成员消费审计。

## 团队共享钱包

告别个人垫付报销或多人共用同一把个人 API Key 的隐患：

- **团队所有者**向团队空间内的**共享钱包**统一充值美元余额。
- 成员创建的**团队专属 API Key**在调用模型时，直接从团队共享钱包实时扣费。
- 成员原有的个人钱包与个人密钥仍保持完全独立，互不干扰。

::: tip 坚持“一人一 Key”原则
建议团队内每位成员都在团队空间下创建并使用自己的专属 API Key，而非线下转发同一把密钥。这样既能精准核算个人/项目消耗，又能在成员离职时单独吊销其权限而不影响团队其他人。
:::

## 角色模型说明

团队空间支持三类明确划分的身份：

| 身份角色 | 适用对象 | 钱包与计费方式 | 生命周期控制 |
| :--- | :--- | :--- | :--- |
| **团队所有者（Owner）** | 团队负责人或财务管理员 | 负责为共享钱包充值与管理团队预算 | 拥有成员邀请/移出、员工子账号管理及全局审计权限 |
| **团队成员（Member）** | 受邀加入团队的平台已有注册用户 | 团队专属 Key 从团队共享钱包扣费；个人空间保持独立 | 所有者可随时调整其权限或将其移出团队 |
| **独立团队员工子账号（Staff Sub-Account）** | 由团队直接创建的内部员工专用账号 | 直接归属团队空间并走共享钱包计费，无需员工自行外部注册 | 由团队所有者直接创建、启停或彻底禁用 |

### 如何选择“邀请成员”还是“员工子账号”？

- **邀请团队成员**：适合协作者本身已有 ADTY AI 账号、希望在同一登录身份下自由切换个人与团队空间的场景。
- **创建独立团队员工子账号**：适合公司集中发放内部账号、希望员工登录凭据的生老病死完全由团队统一管控的场景。

## 创建团队专属 API Key

1. 登录 [https://www.adtyai.com](https://www.adtyai.com) 并切换到对应团队空间（或在新建令牌时选择团队计费归属）。
2. 为该令牌选择一个具体模型分组（详见[渠道可用性与分组选择](/zh-cn/guides/channel-status)）。
3. 按需设置单 Key 美元消费上限、允许调用的模型列表、IP 白名单与过期时间。
4. 将生成的 `sk-...` 密钥配置到成员的 CLI、IDE 或业务服务中。

所有使用该 Key 发起的请求都将自动从团队共享钱包扣费，并归集到团队消费账单中。

## 用量可见性与成本审计

- **团队所有者**：可在团队视图中汇总查看所有成员、员工子账号及各把团队 Key 的消耗明细与趋势，轻松识别异常调用峰值并完成内部成本核算。
- **普通团队成员**：可查看自己名下团队 Key 的调用日志、Token 拆解与 Request ID，便于自查缓存命中与排查报错，同时不会看到其他成员的调用数据。

## 成员移出即时生效

团队安全回收在网关层实时执行，无需等待缓存过期：

- 一旦将某位**团队成员**移出团队，或禁用某个**独立团队员工子账号**，该用户关联的全部团队专属 API Key 会**立即失效并被拦截**，无法继续产生任何扣费。
- 团队内其他成员正常使用中的 API Key 不受任何影响。
- 历史消耗日志仍会完整保留在团队账单中，方便后续对账与合规留痕。
