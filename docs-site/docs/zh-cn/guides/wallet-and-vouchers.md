# 余额充值、充值赠送与额度兑换码

ADTY AI 采用统一的美元（USD）预充值钱包体系，随充随用、按实际消耗实时扣费，所有充值与消耗流水均可在控制台透明核对。

## 在线充值说明

登录控制台 [https://www.adtyai.com](https://www.adtyai.com) 后进入**钱包**页面即可完成充值：

1. 输入要充值的美元金额（或直接点选快捷金额）。
2. 选择上方展示的当前已启用在线支付方式。
3. 核对结算金额（包含汇率换算及系统自动匹配的充值赠送）并完成支付。
4. 支付确认后，对应美元余额将自动计入账户钱包。

### 未支付订单复用与上限机制

为避免重复下单造成混淆或误付：

- **待支付订单自动复用**：如果账户中已有同金额或同通道的有效待支付订单，系统会优先复用该待支付订单，避免无意义地反复创建新单。
- **最多保留 10 笔未支付订单**：单个账号同时最多允许存在 **10 笔未支付订单**。达到上限时，请先在充值记录中完成支付或手动取消不再需要的旧订单，再发起新充值。

::: tip 到账时效参考
支付宝、微信支付等在线通道通常在付款完成后数秒内自动入账；USDT 链上充值需等待所选公链达到确认数后自动入账，转账时请务必严格核对所选网络与页面提示的精确金额。
:::

## 充值赠送（Recharge Bonus）

当当前站点按支付方式配置了**充值赠送**活动时：

- **按支付方式自动生效**：赠送比例会根据你选择的在线支付方式自动计算，无需额外输入优惠码。
- **下单前实时预览**：在钱包充值确认区域即可直接看到本次充值预计额外获赠的美元额度。
- **随单同步入账**：订单支付成功后，本金与赠送额度将一并记入你的钱包流水。

充值赠送规则按当前站点各支付方式的运营配置动态生效，请以钱包页面下单时的实时展示为准。

## 额度兑换码（Quota Vouchers）

如果你从活动赠送、合作伙伴或团队管理员处获得了**额度兑换码**：

1. 进入控制台**钱包** → **额度兑换码**区域。
2. 粘贴兑换码（注意去除首尾多余空格）并点击兑换。
3. 验证通过后，兑换码面值对应的美元额度会立即入账。

::: warning 无效尝试频控保护
为防止恶意枚举与暴力猜测兑换码，短时间内连续提交多次无效兑换码将触发频控保护并进入临时冷却期。如遇提示请仔细核对字符（如数字 `0` 与字母 `O`、数字 `1` 与字母 `I`），稍后再试。
:::

## 透明的按量计费消费日志

每一次通过个人钱包或团队钱包结算的 API 请求，都会在控制台**消费日志**中留下完整可审计记录：

- **时间与 Request ID**：精确到秒的请求时间以及唯一追踪编号，提交[支持中心](/zh-cn/guides/support)工单时可直接附带。
- **API Key 与模型分组**：明确标识扣费所用的令牌及具体模型分组。
- **模型与 Token 明细**：清晰列示输入 Token、输出 Token、提示词缓存读取/写入 Token、推理 Token 或图像生成数量。
- **精确美元扣费与耗时**：展示按分组倍率核算后的实扣金额，以及首字/总响应耗时。

如果是多人团队共同使用，建议了解[团队协作与共享钱包](/zh-cn/guides/teams)，集中管理预算与员工密钥。
