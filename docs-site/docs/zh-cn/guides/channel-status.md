# 渠道可用性与分组选择

ADTY AI 提供公开透明的**渠道状态**实时监测面板，帮助你在创建 API Key 或切换业务线路前直观评估各具体模型分组的健康度。

实时状态页入口：[https://www.adtyai.com/model-status](https://www.adtyai.com/model-status)

## 如何读懂渠道状态页

面板上的每条模型与渠道记录均展示三项核心可用性指标：

### 1. 24 小时心跳柱（Heartbeat Bars）

由左（24 小时前）至右（最新）排列的一组竖条，反映自动化探针在过去 24 小时内每个时间窗口的检测结果：

- **绿色**：探针调用正常通过，响应延迟处于健康区间。
- **黄色 / 琥珀色**：该时间段出现部分降级、偶发重试或延迟偏高。
- **红色**：该窗口内连续探测失败或上游服务出现中断。
- **灰色 / 空白**：该时段暂无探测采样（例如刚上线的新增线路）。

将鼠标悬停在任意一根心跳柱上，即可查看该时间切片的具体时间范围与探测详情。

### 2. 响应延迟（Latency）

展示上游线路在健康检查中的响应速度。对比不同具体分组的延迟数据，可以帮助你区分适合高频交互编程（如 Claude Code、Codex CLI）的低延迟线路与适合异步批处理的性价比线路。

### 3. 成功率（Success Rate）

展示近期探测请求无 `5xx` 报错、无超时顺利完成的比例。对于生产服务或长时间运行的自动化 Agent 任务，建议优先选择 24 小时心跳持续稳定、成功率高的具体模型分组。

## 创建 API Key 时如何选择具体模型分组

在 ADTY AI 中，每把 `sk-...` API Key 都绑定到一个明确的**具体模型分组**。具体模型分组决定了：

- 你的请求将由哪一组上游渠道池承接
- 该 API Key 允许调用哪些模型 ID
- Token 与图像计费所适用的价格倍率

### 推荐选组流程

1. **查看控制台「价格」页面**：对比各具体模型分组包含的模型清单、计费倍率及适用定位。
2. **对照 [https://www.adtyai.com/model-status](https://www.adtyai.com/model-status)**：核实目标分组内你常用模型的 24 小时心跳柱、延迟表现与成功率。
3. **新建 API Key 并绑定具体分组**：在令牌创建页面直接选定目标具体分组。
4. **校验可用模型列表**：创建完成后可调用 `GET https://api.adtyai.com/v1/models` 确认该 Key 实际可见的模型 ID（参见[API 参考](/zh-cn/api/)）。

::: tip 后续切换分组很简单
如果业务阶段变化（例如从低成本评测切换到高稳定性生产线路），只需新建一把绑定到新具体分组的 API Key（或在控制台允许的情况下调整 Key 所属分组），再更新客户端中的密钥即可。
:::

## 遇到上游波动时的排查思路

若客户端频繁出现超时或 `502` / `503` / `504` 错误：

1. 先打开 [https://www.adtyai.com/model-status](https://www.adtyai.com/model-status)，确认目标模型或分组是否正处于上游波动窗口。
2. 查看同样提供该模型的其他具体分组是否保持绿色心跳与正常延迟。
3. 若状态页显示正常但你的请求仍持续失败，请在**消费日志**复制对应的 **Request ID**，通过[支持中心](/zh-cn/guides/support)提交工单协助核查。
