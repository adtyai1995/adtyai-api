## 邀请链接与首单归因机制

1. 登录控制台 [https://www.adtyai.com](https://www.adtyai.com) 并进入**推广返佣**页面。
2. 复制你的专属邀请链接或邀请码，分享给朋友、团队成员或技术社区读者。
3. 新用户通过你的邀请链接打开站点并完成注册（或在注册页填写你的邀请码），即可建立推广归因关系。
4. 被邀请人自首笔有效付费充值起产生的符合条件的在线充值订单，都将按当前生效比例为你计提一级直推佣金。

::: info 归因提示
请提醒受邀用户在访问你的专属链接后于同一浏览器会话内直接注册，或在注册时手动填入邀请码。未绑定邀请关系且已完成首单充值的账号无法事后补录归因。
:::

## 佣金观察期 / 冻结期

被邀请人付款成功后，对应佣金会先进入**观察期（冻结期）**，具体天数以上方实时规则卡片为准：

- 设置观察期是为了覆盖在线支付渠道结算及合理的退款/拒付保护周期。
- 若对应充值订单在观察期内发生退款或撤销，该笔待结算佣金将自动取消。
- 观察期满且无退款争议后，冻结佣金会自动转为**可兑现佣金余额**。

## 佣金兑现方式

可兑现佣金支持以下两种使用途径（外部提现以当前站点实际开启状态为准）：

### 1. 转入账户余额（全站点默认支持）

- **手续费**：**0%**
- **最低门槛**：**$0**（无起转金额限制）
- **到账速度**：**即时到账**，无需人工审核

转入后的金额立即进入你的个人美元钱包，可直接用于任意大模型 API 调用。

### 2. 外部现金提现（仅当当前站点启用时开放）

若上方卡片显示当前站点已开启外部现金提现方式（例如支持指定网络的 USDT 或支付宝）：

- 提现通道、最低提现金额及单笔固定手续费均以上方实时同步参数与控制台推广页提示为准。
- 提交外部提现申请后，将经平台风控与人工审核后再行打款。
- 填写收款账号或 USDT 地址与链网络时请务必逐字核对，链上转账一旦发出无法追回。

## 反作弊与合规红线

为保障真实推广者的长期收益，平台严格禁止以下违规行为：

- **禁止自推自买**：注册关联小号邀请自己，对自身消费套取返佣折扣。
- **禁止循环互推**：多个关联账号或同一主体之间互相邀请形成闭环返佣链。
- **禁止虚假刷量**：批量机器注册、虚假刷单套利、恶意品牌词竞价或发布误导性宣传内容。

::: danger 违规处理
经风控核实存在自推、循环互推或欺诈性充值行为的账号，平台有权清零待结算及违规佣金，取消推广资格，并视情节冻结相关账号。
:::
