# 支持中心（工单）

如遇到充值未到账、API 报错、模型分组咨询或账号安全问题，请直接在控制台 [https://www.adtyai.com](https://www.adtyai.com) 提交支持工单。

## 如何提交支持工单

1. 登录 [https://www.adtyai.com](https://www.adtyai.com)，在左侧导航栏点击**支持中心（工单）**。
2. 点击**新建工单**，选择最贴合问题类型的**工单分类**（例如：充值与账单、API 与模型问题、账号安全、其他咨询）。
3. 填写清晰的标题与简明的问题描述，说明实际现象与复现步骤。
4. 点击提交，即可与支持人员在同一工单会话中持续沟通。

### 附带以下信息可大幅加快排查

- **API 调用问题**：控制台**消费日志**中的 **Request ID**、调用时间、模型名称、HTTP 状态码及脱敏后的报错 JSON。
- **充值与账单问题**：订单号、支付方式、付款时间及支付凭证截图。
- **客户端配置问题**：客户端名称及版本（如 Claude Code、Codex CLI、Cherry Studio）、操作系统与脱敏后的配置片段。

## 上传问题截图

可在新建工单或后续回复中直接上传图片附件：

- **单张图片大小上限**：不超过 **5 MB**
- **单个工单图片数量上限**：最多 **6 张**

上传支付回执或终端截图前，建议顺手裁切掉无关的个人隐私信息。

## 工单文本 API Key 自动脱敏

工单系统内置了自动脱敏保护机制：当你不慎在工单正文或回复内容中粘贴了标准 `sk-...` 格式的 API Key 时，系统会在保存前自动识别并遮蔽密钥内容。

::: tip 仍建议发单前自行移除敏感信息
尽管系统会对工单文本中的 API Key 自动脱敏，仍请勿在工单正文或截图中贴出完整 API Key、个人访问令牌（PAT）、账号密码或 2FA 恢复码。若截图中不慎露出完整密钥，请立即前往**令牌 / API Key** 页面禁用并重新生成。
:::

## 查看回复与跟进进度

- 随时打开控制台**支持中心**即可查看工单当前状态（处理中、已回复、已解决/已关闭）以及客服的最新回复。
- 同一问题请直接在原工单下追加回复补充材料，无需重复提交多张相同工单。
- 问题确认解决后，可直接在工单详情页将其标记为已关闭。
