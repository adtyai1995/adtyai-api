# 分站合作介绍

<MainSiteOnly>

依托 ADTY AI 成熟的底层网关、上游路由与计费体系，快速上线属于你自己的独立白标大模型 API 平台，无需从零开发网关转发、支付对账与控制台系统。

## 分站合作核心能力

ADTY AI 分站合作面向渠道代理、开发者社区、AI 工具工作室及区域运营商，提供完整自主的品牌化运营套件：

### 独立白标品牌体系

- **全站自定义品牌**：独立配置站点名称、Logo、Favicon、首页文案、站点公告与品牌视觉风格。
- **独立法律条款页面**：在你的域名下发布专属《用户协议》《隐私政策》与《退款政策》。
- **文档站自动白标**：挂载于分站 `/docs/` 的文档中心会自动同步你的站点名称、Logo、控制台网址、专属 API 域名、实时启用的支付方式以及推广返佣规则。

### 独立双域名架构

- **专属双域名绑定**：绑定你自己的控制台域名（如 `www.example.com`）与专用 API 网关域名（如 `api.example.com`），保持前后端流量清晰隔离。
- **前后端职责分离**：网站域名用于控制台与白标文档展示，专用 API 域名承载高并发模型中转请求，两者互不干扰、稳定运行。

### 自主商业化定价与营销工具

- **独立零售倍率**：在供货结算之上完全自主设定面向终端用户的零售价格倍率与毛利策略。
- **灵活充值赠金活动**：在分站后台按支付通道或充值档位自定义充值赠金规则。
- **独立推广返佣体系**：自由开关分站推广返佣计划，自主设定返佣比例、观察期天数及提现渠道。

### 完整后台运营管理

- **团队与员工子账号**：支持为分站运营团队分配独立员工子账号与细粒度管理权限。
- **内置客户工单中心**：在自有品牌控制台内统一受理用户工单、查看截图并及时回复。
- **自定义邮件通知**：接入自有品牌发信邮箱 / SMTP 服务，统一发送验证码与业务通知邮件。
- **每日结算单**：清晰呈现每日流水、供货成本、赠金补贴、返佣支出与净结算数据，账目一目了然。

## 分站等级与供货折扣

分站等级与供货折扣暂未公开统一标准表，具体政策请联系客服咨询。

平台会根据合作伙伴的目标客群、业务模式、区域特性与预计体量提供定制化方案，不对外公示固定分级折扣表。

## 保证金说明

根据分站合作等级与平台现行运营规则，开通或升级分站可能涉及**保证金**机制。总体而言，保证金用于作为分站合规经营押金，并在适用场景下可兼作可选的营销活动兑付缓冲资金，以保障每日结算连续性与终端用户权益。

保证金的具体要求因合作方案与平台当前政策而异，请在实际签约与开通前联系平台客服获取准确说明。

## 如何申请开通分站

欢迎联系我们沟通分站合作细节：

1. 登录 [https://www.adtyai.com](https://www.adtyai.com)，通过[支持中心](/zh-cn/guides/support)提交合作咨询工单（或直接联系平台官方客服）。
2. 简要介绍你的计划品牌名称、目标用户群体、域名准备情况以及预计月度调用体量。
3. 合作专员将为你详细介绍当前分站等级方案、供货政策、保证金规则以及双域名上线流程。
