## 合理使用规范

注册账号或通过 `https://api.adtyai.com` 发起模型调用，即视为您同意遵守以下基本原则：

- **合法合规调用**：禁止将接口用于违法违规用途、恶意软件编写、未授权渗透测试、欺诈、垃圾信息群发，或违反适用法律法规与上游模型厂商安全政策的内容生成。
- **凭证与账号诚信**：请妥善保管登录密码、2FA 离线恢复码、个人访问令牌（PAT）及 `sk-...` API Key；严禁恶意注册虚假账号、脚本刷号或操纵推广返佣机制。
- **友好访问行为**：遵守各 Key 的额度上限、并发及频率限制，不得对网关基础设施实施探测、攻击、绕过鉴权或异常施压。

::: warning 违规处置说明
如账号存在违反《用户协议》或恶意套利充值、兑换码、推广返佣等行为，平台有权暂停相关 API Key 或限制账号权限并进行合规核查。
:::

## 计费透明度说明

ADTY AI 坚持清晰、可核对的按量计费机制：

- **美元统一记账**：钱包余额、额度兑换码面值与每次请求扣费均以美元（USD）为计价单位。
- **按实际用量扣费**：单次调用费用严格依据模型实际消耗的输入 Token、输出 Token、提示词缓存命中/写入 Token、推理 Token 或图像生成张数，结合该 API Key 所绑定具体模型分组的公开倍率计算。
- **逐笔日志可查**：所有计费请求均记录在控制台**消费日志**中，展示调用时间、模型名称、Token 明细、精确美元扣费、耗时以及用于排查的 Request ID。
- **无隐形自动续费**：常规模型调用仅从预充值个人钱包或团队共享钱包扣款，触及 Key 限额或余额耗尽时将停止扣费，不存在未授权的周期扣款。

如对账单或条款有任何疑问，欢迎通过[支持中心](/zh-cn/guides/support)提交工单咨询。
